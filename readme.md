# AutoCutVideo V2.6.3

AutoCutVideo_v2 是一款基于 PyQt6 的智能化桌面视频剪辑与自动化处理工具，界面采用了类似剪映的现代深色主题，旨在通过 AI 与自动化脚本提升视频创作和后期剪辑效率。

## 🌟 核心功能

1. **可视化多轨时间轴编辑器**  
   提供现代化的 UI 界面，支持多轨道的视频片段（Clip）展示、拖拽与管理，实时预览视频画面（底层基于 OpenGL 与 PyQt6 渲染）。
   
2. **AI 智能字幕生成与校对**  
   - 自动提取视频音频并识别生成 SRT 字幕文件。
   - **大模型字幕润色**：无缝接入 LLM（如 Gemini 等大语言模型），在保证严格时间轴格式不变的前提下，对识别出的错别字进行智能校对。
   - **自定义字幕压制**：内置多种字幕样式（如经典白边、复古黄字、综艺橙蓝、影院大字等），一键将字幕硬压制到视频中。

3. **自动化 B-Roll (空镜头) 处理**  
   基于文本或时间轴规则自动匹配与插入 B-Roll 素材，丰富视频画面，减少人工剪辑工作量。

4. **封面与图像智能裁剪**  
   内置多套视频封面模板，支持自定义封面生成与图片智能裁剪。

5. **幻灯片 / PPT 转视频**  
   提供幻灯片处理器，支持将一系列静态图片或内容结合音轨自动化生成连贯的视频流。

## 🛠️ 技术栈

- **前端 UI**: `Python 3` + `PyQt6` (界面, QSS 深色主题, 音视频预览)
- **底层音视频处理**: `MoviePy`, `FFmpeg` (`imageio_ffmpeg`)
- **AI 赋能**: 兼容 OpenAI API 格式的 LLM 接口调用（主要用于字幕处理与校对）

## 📂 核心项目结构

- `main.py`: 程序主入口，负责构建 PyQt6 主窗口和各个 Tab/面板。
- `core_processor.py`: 核心处理模块，包含音频提取、调用大模型校对字幕、字幕硬压制等关键逻辑。
- `timeline_ui.py` / `timeline_model.py` / `timeline_renderer.py`: 时间轴组件的核心数据模型、UI 交互逻辑以及渲染导出引擎。
- `auto_broll.py`: 自动 B-Roll 视频素材处理模块。
- `slide_processor.py`: 幻灯片与图像序列视频化处理器。
- `cover_generator/`: 独立的视频封面生成工具包（含独立的 GUI 程序、模板、文档、启动脚本及 PyInstaller 打包配置）。
- `image_cropper.py`: 图片裁剪工具。
- `GEMINI_接入指南.md` / `genimi版本说明.txt`: 大模型 API 接入与配置相关文档。
- `*.spec`: 提供给 PyInstaller 的打包配置文件，用于将 Python 脚本编译为独立执行程序。

## 🚀 快速开始

1. **环境安装**：
   确保系统已安装 Python 3.8+。
   ```bash
   pip install -r requirements.txt
   ```
2. **配置环境变量**：
   复制 `.env.example` 并重命名为 `.env`，填入你的 API Key 等必要配置（如用到大模型字幕校对）。
3. **运行程序**：
   ```bash
   python main.py
   ```
   
> **提示**：在使用视频压制与媒体处理功能前，系统将自动检测 FFmpeg，请确保其已配置或随 `imageio_ffmpeg` 自动安装。
